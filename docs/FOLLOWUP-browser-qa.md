## 발견된 문제점

### [중요] AUTH-02 requestReset() 오류 처리 누락 → 수정 완료 (2026-10-16)

- 수정 커밋: `cc63e7e` (별도 커밋, PR #2 브랜치)
- 수정 내용:
  - `requestReset()`, `confirmReset()`에 try/catch 추가
  - 네트워크 오류 시: "요청에 실패했습니다. 네트워크 연결을 확인하고 다시 시도하세요."
  - 서버 오류 시: 서버 메시지 또는 "서버 오류가 발생했습니다. 잠시 후 다시 시도하세요."
  - 요청 중 버튼 비활성화, 완료 후 복원
  - 빈 오류 배너 숨김 (`msg err` → `msg`로 초기 클래스 변경)
- 검증 (Node DOM 시뮬레이션, 5개 시나리오 전부 통과):
  1. 네트워크 오류 → 오류 메시지 표시, 버튼 복원
  2. 서버 오류 (메시지 있음) → 서버 메시지 표시
  3. 서버 오류 (메시지 없음) → 기본 메시지 표시
  4. confirmReset 네트워크 오류 → 오류 메시지 표시, 버튼 복원
  5. 정상 흐름 → 2단계 전환 정상

### [경미] 빈 오류 배너 렌더링

- 두 페이지 모두 초기 로드 시 빈 오류 배너가 옅은 분홍색 띠로 표시됨
- 메시지 없을 때는 숨김 처리 권장
