## 검증 완료 항목 (참고)

- 로그인/로그아웃/토큰 갱신/로테이션/비밀번호 재설정 API 전 플로우: 실제 HTTP 서버 + curl로 검증
- 338개 단위 테스트 (MockMvc): 전부 통과
- 정적 파일: HTML well-formed, auth.js 문법, API 경로 일치, viewport·44px 터치 적용

## QA 수행 조건

- 개발 서버 기동 (`~/workspace/rea-academy`, H2, 8081 포트)
- 테스트 계정 시딩 (data.sql 또는 원장의 자격 설정 API)
- 브라우저에서 `http://localhost:8080/screens/AUTH-01-login.html` 접속 (프록시 필요)
