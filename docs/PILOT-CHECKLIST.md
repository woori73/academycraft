## 검증 항목

### 1. 원장·강사·학부모 권한별 로그인 및 접근

| # | 검증 항목 | 방법 | 기대 결과 |
|---|---|---|---|
| 1-1 | 원장 로그인 | X-Auth-Key로 API 호출 | 200, 전체 메뉴 접근 |
| 1-2 | 강사 로그인 | 강사 키로 API 호출 | 200, 담당 반만 접근 |
| 1-3 | 학부모 로그인 | 학부모 키로 API 호출 | 200, 자녀 정보만 접근 |
| 1-4 | 미인증 접근 차단 | 키 없이 API 호출 | 401 |
| 1-5 | 타 학원 접근 차단 | 다른 academyId로 호출 | 403 |

### 2. 학생 등록·수정·비활성 처리

| # | 검증 항목 | 방법 | 기대 결과 |
|---|---|---|---|
| 2-1 | 학생 등록 | POST /students | 201, 학생 생성 |
| 2-2 | 학생 정보 수정 | PUT /students/{id} | 200, 이름·학년·학교 변경 반영 |
| 2-3 | 학생 목록 조회 | GET /students | 활성 학생만 표시 |
| 2-4 | 학생 비활성 처리 | (API 또는 UI) | 목록에서 제외 |
| 2-5 | 비활성 학생 조회 | GET /students/inactive | 원장만 조회 가능 |

### 3. 반 배정 및 강사 관리

| # | 검증 항목 | 방법 | 기대 결과 |
|---|---|---|---|
