## 3. BuildIt 연동 지점

상세 설계: `docs/buildit-integration.md`

| 연동 | 방향 | 방식 | AcademyCraft 측 작업 |
|---|---|---|---|
| 홈페이지 → REA 이동 | BuildIt → REA | 딥링크 (1단계) | 없음 (URL 규약만 준수) |
| 입학상담 접수 | 방문자 → REA | 공개 API + 폼 (P1-5) | inquiries/public 신설 |
| SSO | BuildIt → REA | 일회용 서명 토큰 (2단계) | 토큰 검증 엔드포인트 |
| 공개 요약 위젯 | REA → BuildIt | BFF 읽기 API (3단계) | 읽기 전용 요약 API |
| 데이터 쓰기 | — | **금지** | 같은 데이터를 양쪽에서 쓰지 않음 (원칙) |

**경계**:
- BuildIt `wemade-reorg` 코드 수정은 별도 승인 필요
- BuildIt 기존 테이블에 컬럼 추가·변경 금지 (필요 시 REA 측 별도 테이블)
- 학부모 개인정보를 홈페이지 공개 API로 노출 금지
- 학원 식별자: BuildIt `academy_id` = REA `academyId` 동일값 사용
