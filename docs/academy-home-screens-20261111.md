# 학원 홈 연동 화면 변경 (2026-11-11)

BuildIt 학원 홈(`/dashboard`)에서 오늘 수업·학생 챙기기로 바로 들어오는 화면 동작. 백엔드·DB·게이트웨이 허용 목록 변경 없음(기존 허용 화면·API만 사용).

| 화면 | 주소 조건 | 변경 |
|---|---|---|
| ATT-03 반별 출결부 | `?classId=&date=YYYY-MM-DD` | 주소로 반·날짜 자동 조회, 조회 조건을 주소에 남겨 새로고침해도 유지. 기본 날짜는 한국 날짜(예전 `toISOString()`은 오전 9시 전 전날). 행마다 출석·지각·결석(+ 조퇴·하원) 선택 + 메모 → 저장. 지난 날짜 출결부에서 저장하면 그 날짜(수업 시작 시각, 없으면 정오)로 기록(예전에는 '지금'으로 저장됨). 기존 기록 정정은 행 안 폼에서 구분 선택 + 사유 필수 → `PUT /attendance/{id}`(정정 이력 보관). prompt 없음 |
| MBR-01 학생 목록 | `?classId=&studentId=` | 등록·수정 한 폼(이름·학년·학교·학부모·연락처, 예전 등록은 학교 누락). 상단 `재원생 전체 n명` = 활성 학생 전체(학원 홈 재원생 수와 같은 `GET /students`), 검색·반 필터 결과는 따로 표시. 재원/비활성 전환. 학생 상세: 소속 반(반 상세 기준, 여러 반도 한 사람)·오늘 출결부 링크·최근 30일 출결·상담 기록·상담 작성 링크. prompt 없음 |
| CLS-03 반 상세 | `?id=` | 「이 반 오늘 출결부」「이 반 학생 명단」 링크 |
| CNS-03 상담 기록 | `?targetStudentId=` | 그 학생 상담만 조회(서버 기존 파라미터) |
| CNS-04 상담 기록 작성 | `?studentId=` | 학생 미리 선택 |
| 공통 메뉴(common-service.js) | — | 「통합 대시보드」→「학원 홈」, 「정보」(`/dashboard/info`) 추가 |

- 권한: 기존 `ReaAccessRules` 그대로. 강사는 학생 수정(`PUT /students/{id}`)이 403 → 화면에 "학생 정보 수정은 원장 권한입니다" 안내. 출결 기록·정정은 원장·강사 모두 가능(기존 규칙).
- 규칙 함수: `frontend/components/screen-rules.js`(UMD), 테스트 `frontend/tests/screen-rules.test.cjs`(CI `node --test frontend/tests/*.test.cjs`).
- 반 목록의 `studentCount`는 비활성 학생의 배정까지 센다(기존 동작, 변경 안 함). 학원 홈은 출결부(활성 수강생) 인원을 쓴다.
- 배포: AcademyCraft 정적 화면은 JAR에 포함되므로 운영 반영은 AcademyCraft 수동 배포 후다.
